# МЯСО — апка в Telegram

Бот: @m9sooobot. Апка — обычный сайт, который Telegram открывает внутри себя.

## Как это работает

1. **Сайт.** `index.html`, `style.css`, `app.js`. Лежит в интернете по адресу с https.
2. **Бот.** Ему говорят адрес сайта, и в чате с ботом появляется кнопка «Открыть».
3. **Связь с Telegram.** Скрипт `telegram-web-app.js` в `index.html` даёт сайту имя того, кто открыл,
   системную кнопку «Назад», вибрацию и ссылки внутри Telegram. Вне Telegram сайт тоже открывается,
   но пишет «Открыто не в Telegram».

## Файлы

| Файл | Что в нём |
|---|---|
| `content.js` | весь контент: гайды, промпты, видео, инструменты. Здесь же примеры, как добавлять |
| `app.js` | логика: загрузка, разделы, кнопки |
| `style.css` | внешний вид |
| `set-menu.sh` | ставит кнопку в боте: `./set-menu.sh https://адрес-апки/` |
| `.env` | токен бота. Только на этом компьютере, в git не попадает |

## Как обновить апку

Поменял файлы → `git commit` → `git push`. Через минуту в Telegram откроется новая версия.

## Прямая ссылка на апку

Кнопка в боте работает сразу. Чтобы была ссылка вида `t.me/m9sooobot/app`, которую можно вставить в пост,
в @BotFather: `/newapp` → выбрать бота → название, описание, картинка 640×360 → адрес апки → короткое имя `app`.
Ссылка `t.me/m9sooobot/app?startapp=prompts` откроет сразу раздел «Промпты».
